# Task 20 实现总结：顾客小程序菜单浏览与购物车

## 实现概述

本任务实现了顾客小程序的核心功能：菜单浏览和购物车管理。包括购物车状态管理（Pinia Store）、菜单页面（分类展示、搜索、购物车悬浮栏）、购物车详情页面，以及完整的单元测试和属性测试。

## 实现内容

### 1. 购物车状态管理 (`src/stores/cart.ts`)

实现了完整的购物车 Pinia Store，包含以下功能：

#### 状态

- `items`: 购物车商品列表
- `totalAmount`: 计算属性，总金额（单位：分）
- `totalQuantity`: 计算属性，商品总数量

#### 方法

- `addItem()`: 添加商品到购物车，相同商品自动累加数量
- `updateQuantity()`: 更新商品数量，数量为 0 时自动移除
- `removeItem()`: 从购物车移除商品
- `clearCart()`: 清空购物车
- `getItemQuantity()`: 获取指定商品的数量

#### 核心逻辑

- **总金额计算**：`totalAmount = sum(item.unitPrice × item.quantity)`
- **自动移除**：数量为 0 时自动从购物车中移除该项
- **商品合并**：相同 `dishId` 和 `skuId` 的商品自动累加数量

### 2. 菜单浏览页面 (`src/pages/menu/index.vue`)

实现了完整的菜单浏览功能：

#### 功能特性

- **搜索功能**：支持按菜品名称搜索
- **分类展示**：横向滚动的分类标签，点击切换分类
- **菜品列表**：按分类分组展示上架菜品
- **购物车操作**：
  - 未添加时显示"加入购物车"按钮
  - 已添加时显示数量控制器（+/-）
  - 实时显示购物车中的商品数量
- **购物车悬浮栏**：
  - 显示购物车图标和商品总数量徽章
  - 显示总金额
  - 点击跳转到购物车页面

#### 数据加载

- 从 `/api/categories` 加载分类列表
- 从 `/api/dishes` 加载菜品列表
- 只显示 `isAvailable = true` 的上架菜品

#### 用户体验

- 加载状态提示
- 空状态提示（无菜品/搜索无结果）
- 添加成功 Toast 提示
- Session 过期自动跳转扫码页

### 3. 购物车页面 (`src/pages/cart/index.vue`)

实现了完整的购物车管理功能：

#### 功能特性

- **空购物车状态**：显示空状态提示和返回按钮
- **商品列表**：
  - 显示商品图片、名称、SKU、单价
  - 数量控制器（+/-）
  - 支持直接输入数量
  - 显示每项小计金额
- **底部结算栏**：
  - 显示总金额
  - 清空购物车按钮
  - 提交订单按钮

#### 交互逻辑

- 减少数量到 0 时弹出确认删除对话框
- 清空购物车前弹出确认对话框
- 输入无效数量时显示错误提示
- 点击提交订单跳转到订单确认页

### 5. 属性测试 (`src/test/stores/cart.property.test.ts`)

实现了 7 个属性测试，每个测试运行 100 次迭代：

#### 属性 3：购物车状态不变量

**属性 3.1**：总金额应该始终等于所有商品的 `unitPrice × quantity` 之和

- 生成随机操作序列（添加、更新、移除）
- 验证总金额计算的正确性

**属性 3.2**：数量为 0 的商品不应该出现在购物车中

- 执行随机操作后验证所有商品数量 > 0

**属性 3.3**：将商品数量设置为 0 后，该商品应该从购物车中移除

- 添加多个商品，随机选择一个设为 0
- 验证该商品已被移除

**属性 3.4**：购物车总数量应该等于所有商品数量之和

- 验证 `totalQuantity` 计算的正确性

**属性 3.5**：相同商品应该合并而不是重复

- 多次添加相同商品
- 验证购物车中只有一个条目且数量正确

**属性 3.6**：清空购物车后，所有状态应该重置

- 验证 `clearCart()` 后所有状态归零

**属性 3.7**：金额计算不应该溢出或产生负数

- 验证总金额始终是非负有限数
